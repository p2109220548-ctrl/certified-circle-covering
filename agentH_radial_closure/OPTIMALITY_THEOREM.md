# 旋转平均最优性定理：测度法的精确天花板

**agentH_radial_closure · 2026-09-26**　|　状态：证明完成 ✅

---

## 1. 定理陈述

**定理（旋转平均 / 径向族最优性）。**
设 μ 是单位圆盘 D 上的任意 Borel 概率测度，r > 0。则存在 [0,1] 上的概率测度 ν
（μ 的径向化），使得

    max_{c ∈ ℝ²} μ(B(c, r))  ≥  max_{d ∈ [0, ∞)} F_ν(d)  ≥  V_radial(r),

其中

    F_ν(d) = ∫₀¹ φ_t(d) dν(t),      φ_t(d) = 环核（见下），

    V_radial(r) = inf{ max_d F_ν(d) : ν 概率测度于 [0,1] }。

**推论（测度法天花板）。** 若 V_radial(r) > 1/n，则 n 个半径 r 的圆不能覆盖 D，
即 r_D(n) ≥ r —— 这对**一切**测度论证成立。反之，使 V_radial(r) ≤ 1/n 的最大 r
（记作 r_meas）就是**任何**"造一个测度、证每个球质量 ≤ 1/n"型论证的精确上限。
非径向测度（原子、弧、扇形、任何东西）**不可能超过 r_meas**。

## 2. 证明

### 第一步：径向化

对 μ 定义旋转平均

    ν = (1/2π) ∫₀^{2π} (R_θ)# μ dθ,

其中 R_θ 是绕原点旋转 θ，(R_θ)#μ 是推前测度。ν 是概率测度（凸组合保持质量），
且旋转不变。旋转不变的概率测度完全由其径向剖面 ν̃ = (x ↦ |x|)#μ 决定——
即 [0,1] 上的概率测度 ν̃（下文直接记 ν = ν̃）。

### 第二步：对 φ 平均 = 环核作用

固定 d ≥ 0，令 c(d,φ) = d(cosφ, sinφ)。计算

    A(d) := (1/2π) ∫₀^{2π} μ(B(c(d,φ), r)) dφ
         = ∫_D [ (1/2π) ∫₀^{2π} 1{‖x − c(d,φ)‖ ≤ r} dφ ] dμ(x)    (Fubini，被积非负)。

内层积分：固定 x，s = ‖x‖。把坐标转到 x 的方向为极轴（旋转对称性，被积函数
对整体旋转共变，测度 dφ 平移不变），条件 ‖x − c(d,φ)‖ ≤ r 变成

    d² + s² − 2 d s cosφ ≤ r²  ⟺  cosφ ≥ (d² + s² − r²)/(2 d s)。

分情形（与 `measure_bound.phi` 的精确定义逐条一致）：

- d + s ≤ r：一切 φ 满足 ⟹ 内层 = 1；
- |d − s| ≥ r（且 d+s > r）：无 φ 满足 ⟹ 内层 = 0；
- 否则 φ ∈ [−α, α]，α = arccos((d² + s² − r²)/(2ds)) ⟹ 内层 = α/π。

恰是环核 φ_s(d)：**半径 s 的均匀圆环被球 B(c(d,φ),r) 覆盖的弧长比例，且它对
φ 平均后与 φ 无关**（这正是"环核"名字的由来）。

于是

    A(d) = ∫₀¹ φ_s(d) dν(s) = F_ν(d)。

### 第三步：max ≥ 平均 ≥ 径向最优

对每个 d：max_φ μ(B(c(d,φ), r)) ≥ A(d) = F_ν(d)。

因此

    max_c μ(B(c, r)) = max_{d, φ} μ(B(c(d,φ), r)) ≥ max_d F_ν(d) ≥ V_radial(r)。∎

### 第四步：从测度界到覆盖下界（标准一步，附于此保证自洽）

若 V_radial(r) > 1/n 而某组圆心 C₁,…,C_n 以半径 r 覆盖 D，则

    1 = μ(D) ≤ Σᵢ μ(B(Cᵢ, r)) ≤ n · max_c μ(B(c,r))，

与 max_c μ(B(c,r)) ≥ V_radial(r) > 1/n 矛盾。故 r_D(n) ≥ r。∎

## 3. 这对项目意味着什么

1. **非径向测度前线（原⑤主攻方向）正式关闭。**
   「环 + 原子」「二面角群不变族」「弧族」等一切花样的收益上界 = 0：
   任何测度 μ 的球质量峰值被它的径向化控制。项目工具清单第二图预言
   "新工具必须放弃可加性"——此定理正是该哲学的精确化：**在测度对偶框架内，
   角度结构是幻觉，只有径向剖面是真实的。**

   "我们只做到这里"，而是**整个测度对偶方法类的极限**（差一个环网格离散化
   余量，由 agentH 的 K=320 环机器压到 <1e-5 量级）。

3. **剩余战场明确化。** 0.106 → 真值(~0.113–0.117) 之间只能靠**结构性论证**
   （非测度类）：Fejes Tóth 式 Voronoi 胞腔不等式的有限 n + 有边界版本。
   该路线的核心引理（凸胞腔直径 ≤ 2r 的铺砌中，边界胞腔面积损失的精确记账）
   是真正的公开难点，也是唯一能把下界推过 0.11 的已知型方法。

## 5. 结构性路线图（下一个真前线）

目标：证明型的不等式 π = Σᵢ area(Vᵢ ∩ D) 与胞腔结构联立。

- 每个胞腔 Vᵢ ∩ D 凸、含于 B(cᵢ, r)（Voronoi 胞腔 ⊆ 最近中心之球，因覆盖）。
- 内部胞腔：area ≤ f(kᵢ)·r²，f(k) = (k/2) sin(2π/k)（内接于半径 r 圆的 k 边形
  面积上界），kᵢ = 边数；f(6) = 3√3/2 ≈ 2.598。
- Euler 计数：平面铺砌平均边数 < 6，若 f 对"边数亏量"凸，则 Σ ≤ n·f(6)·r²
  + 边界修正项。**缺口**：边界胞腔（被 ∂D 切割）的面积损失与圆伸出 D 外的
  浪费之间的精确记账——这正是 n=100 有限效应所在，也是全部难度所在。
- 经验标尺：渐近 Kershner 常数给出 r ≥ √(2π/(3√3)/n) ≈ 0.10996；边界浪费
  项使其回落；若能证得 r ≥ 0.11 级别即为本项目下界的代际跨越。

**纪律**：在缺口引理被严格证明并过 soundness 审计（对照构造值 0.11785 的
sanity check：下界必须 ≤ 真值 ≤ 上界）之前，不得声称任何数值。
