# 径向测度对偶下界：r_D(100) ≥ r* 的严格证明

**作者**：agentB（lb-measure）。本文给出一个完全严格、可机器复算的下界证书。
所有数值上界均按"保守方向"舍入；唯一的非严格成分是 IEEE-754 双精度浮点
（相对误差 ~1e-16，证书中统一加 5e-14 绝对膨胀覆盖）。

---

## 1. 对偶引理（测度法下界）

**引理 1（覆盖对偶）**。设 μ 是闭单位圆盘 D 上的 Borel 概率测度。若存在 r > 0 与
δ ≥ 0 使得对平面上**任意**圆心 c 的半径 r 圆盘 B(c,r) 都有

    μ(B(c,r)) ≤ 1/100 − δ,          (★)

则 100 个半径 r 的圆盘不能覆盖 D；从而 r_D(100) ≥ r。若 δ > 0 则覆盖不可能
（结论加强为 r_D(100) > r）。

**证明**。反设 B_1,…,B_100（半径均 r）覆盖 D。则

    1 = μ(D) = μ(∪_i B_i ∩ D) ≤ Σ_{i=1}^{100} μ(B_i ∩ D) ≤ Σ μ(B_i) ≤ 100(1/100 − δ) = 1 − 100δ.

当 δ ≥ 0 时得 1 ≤ 1 − 100δ，故 δ = 0 且每步不等式全部取等；当 δ > 0 直接矛盾。
取等要求 μ(D \ ∪B_i) = 0，这只说明"贴边可行"；而 (★) 对 δ = 0 情形只能给出
r_D(100) ≥ r（弱对偶），δ > 0 给出严格分离。∎

**径向族**。取 μ_{t,w} = Σ_{k=1}^K w_k · σ_k，其中 σ_k 是半径 t_k ∈ [0,1] 的圆周上
的（归一化）弧长均匀测度，w_k ≥ 0，Σ w_k = 1。μ_{t,w} 是 D 上的 Borel 概率测度。
平面上到原点距离 d = ‖c‖ 的圆盘 B(c,r) 的质量为

    F(d) = Σ_k w_k φ_k(d),      φ_k(d) = σ_k(σ_k-圆周 ∩ B(c,r)) ∈ [0,1].

F 只依赖 d ∈ [0, ∞)；且 d > max_k(t_k + r) 时 F(d) = 0。故只需控制
sup_{d ∈ [0, T+r]} F(d)，T = max_k t_k ≤ 1。

## 2. φ_k 的精确公式与导数（含核对）

设 t = t_k, d = ‖c‖。圆周 ∂B(0,t) 上的点 p(θ) = t(cosθ, sinθ)，c = (d, 0)。
p ∈ B(c,r) ⟺ t² + d² − 2td cosθ ≤ r² ⟺ cosθ ≥ γ(d) := (t² + d² − r²)/(2td)。

    φ_t(d) = 0                                   若 |d − t| ≥ r（圆周在盘外，或盘严格在圆内）
    φ_t(d) = 1                                   若 d + t ≤ r（盘包含整条圆周）
    φ_t(d) = α(d)/π                              其余情形；α = arccos γ ∈ (0, π)
    特例 d = 0：φ_t(0) = 1 (t ≤ r), 0 (t > r)；特例 t = 0：点质量，φ = 1 (d ≤ r)。

（θ ∈ [−α, α] 的弧被覆盖，占比 2α/2π = α/π。）

**导数核对**。γ′(d) = (d² + r² − t²)/(2td²)；又

    1 − γ² = [(2td)² − (t²+d²−r²)²]/(2td)² = [(r² − (d−t)²)((d+t)² − r²)]/(2td)²  （平方差分解），

故任务书给出的公式

    α′(d) = −(d² + r² − t²) / [ d · √((r² − (d−t)²)((d+t)² − r²)) ]

**经复核成立**（α′ = −γ′/√(1−γ²)，代入即得）。

**推论（单峰结构，修正任务书一处说法）**。α′(d) = 0 ⟺ d² = t² − r²。因此

* t ≤ r：φ_t 在 [0, ∞) 单调不增（在 [0, r−t] 恒为 1，其后严格递减）；
* t > r：φ_t 在 [0, t−r] 为 0，在 [t−r, √(t²−r²)] 严格递增，
  在 [√(t²−r²), t+r] 严格递减，其后为 0。

即 φ_t 单峰，**峰值点在 p = √(t² − r²) 而非任务书所述的 d = t**（d = t 处
γ = 1 − r²/2t² < γ(p)，故 φ(t) < φ(p)；数值验证：t=1, r=0.106 时
φ(√(1−r²)) = 0.033888 > φ(1) = 0.033871）。本实现的严格上界使用正确的峰值点。

## 3. sup F 的严格上界协议

**临界点集** G₀ = {0, T+r} ∪ {t_k} ∪ {|t_k − r|} ∪ {t_k + r} ∪ {√(t_k² − r²) : t_k > r}
（全部截断到 [0, T+r]）。G₀ 包含每个 φ_k 的**全部**临界点（零点、峰点、斜率间断点）。

**关键观察**：G₀ ∪ 均匀填充点的任何相邻对 [a,b] 的开区间内部不含任何临界点，
故每个 φ_k 在 [a,b] 上单调。于是对任意 x ∈ [a,b]：

    F(x) ≤ F(a) + Σ_k w_k max(0, φ_k(b) − φ_k(a))    （自 a 的单侧界）
    F(x) ≤ F(b) + Σ_k w_k max(0, φ_k(a) − φ_k(b))    （自 b 的单侧界）

取二者较小者：

    bound[a,b] := min(F(a) + Σ w_k max(0,Δ_k),  F(b) + Σ w_k max(0,−Δ_k)),  Δ_k = φ_k(b) − φ_k(a).

则 sup_{[a,b]} F ≤ bound[a,b]，且保守度 ≤ Σ_k w_k|Δ_k| = O(区间长度)。
**注意**：任务书提示的"切点附近用端点 max 会残留 O(√h) 松弛"——双侧 min 界把
切点处的 √ 型松弛也压到 O(h)（切点环的增量 Δ_k 是 F 的真实增量而非松弛，
只有其余光滑环贡献 O(h) 对齐误差），因此不需要对切点做 1e-18 级加密。

**协议**：
1. 网格 = G₀ ∪ 均匀(h₀ = 5e-4)。
2. 计算所有子区间的 bound；对 bound > cap（认证阶段 cap = 1/100）或
   bound 接近当前最大值（默认阶段）的区间二分加密，区间长下限 5e-10，
   点数上限 max(150000, 2.5e6/K)。
3. sup_upper = max_j bound_j + 5e-14（浮点膨胀）。**该上界在任何加密层级下均严格**；
   加密只减小保守度。
4. 认证：反复验证 sup_upper ≤ 1/100；若不满足则 r 缩 1e-6 重来，直至通过。
   LP 阶段网格（均匀 5000 点 + G₀）仅为必要条件搜索，最终以本协议为准。

## 4. LP 搜索与外层优化

固定 t 与 r 后，{w ≥ 0, Σw = 1, F(d_j) ≤ 1/100 ∀网格点 d_j} 是线性系统，
用 scipy linprog (HiGHS) 判可行；对 r 二分（26 轮，分辨率 2e-7）。外层：
K = 10..20 × 7–9 种半径模式（均匀、√、幂 0.7/1.4、边界密集、含原点原子等）
逐 pattern 二分；对最优 pattern 再跑 Nelder-Mead 精修 t（目标 = −best_r）。

## 5. 结果

**认证下界：r_D(100) ≥ r* = 0.105471941**（证书 r = 0.10547194123077391）。

* LP 最优（离散系统）：r_LP = 0.10547272（K = 20 环，Nelder-Mead 精修后）。
* 认证（固定 w、严格 sup 协议二分）：r* = 0.105471941，
  **sup_upper = 0.00999999999984 ≤ 1/100**，双网格复验通过
  （h₀ = 5e-4 与 h₀ = 1.25e-4，n_grid 分别 13526 / 19787），
  并经独立蛮力检查（h = 2e-6 均匀网格直接算 max F = 0.0099999998 ≤ 0.01）。
* 认证损失（r_LP − r*）≈ 8e-7。

## 8. 完备性告诫（soundness caveats）

* 本证明只覆盖**径向（圆周均匀）测度族**；径向族之外（例如含角度结构的测度）
  可能给出更强下界，不在此证书范围内。
* sup_upper 的严格性依赖：(i) φ_k 公式与单峰结构的解析核对（§2）；
  (ii) 临界点全部入格 ⇒ 每个子区间上 φ_k 单调（§3）；(iii) 浮点膨胀 5e-14。
  双精度下 arccos 的相对误差 ~1e-16，远小于膨胀量。
* LP 搜索只是启发（必要条件）；证书的最终有效性**只**依赖 §3 的严格 sup
  协议对最终 (t, w, r) 的验证，与搜索过程无关。
* K = 20 的环数上限与有限搜索模式意味着 0.105471941 是"当前搜索到的最优
  可认证值"，不是径向族内的最优化声明。
